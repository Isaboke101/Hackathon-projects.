# 🚀 Hackathons

Welcome to my Hackathons repository! This is a centralised archive of the projects, prototypes, and software solutions I've built — solo and with teams — during various hackathons.

Hackathons are a great way to rapidly prototype ideas, solve real-world problems under pressure, and learn new technologies. This repository documents that journey.

## 📂 Repository Structure

Each folder in this repository represents a distinct hackathon project. Inside each directory, you'll find the specific source code, design files, and a dedicated `README.md` with setup instructions for that particular event.

### Featured Projects

*   **[📁 Urban-Drain-Digital-Twin](./Urban-Drain-Digital-Twin)**
    *   **Event:** IEEE Tech Ignite Summer School 2026
    *   **Description:** A digital twin used to predict flooding and suggest the best possible routes to avoid flooded areas

*(More projects will be added as I participate in future events!)*

## ⚙️ How to Explore

1. Choose a project folder from the root directory.
2. Navigate inside to view the source code.
3. Read the project-specific `README.md` for instructions on how to install dependencies, configure databases, or wire up any hardware components to run the project locally.
